# 美国FDA 510(k) · 提交前最终自查清单

> 提交eSTAR前逐项打勾。任何P0项没打勾 = 不能提交。

---

## 🔴 P0级（必退/RTA拒收，一个都不能漏）

### 形式审查类（RTA阶段就会被打回）

- [ ] **eSTAR版本正确**：使用最新版（当前7.0，v6.2已退休）
- [ ] **US Agent信息完整**：名称、地址、联系方式都填了
- [ ] **申请人信息完整**：公司名称、地址、FEI号
- [ ] **器械名称正确**：通用名+商品名，和标签一致
- [ ] **Predicate Device信息准确**：名称、K号、是否有效、是否有召回

### 实质内容类（SE阶段会被发补）

- [ ] **实质等同论证完整**：列出了所有差异点，逐条论证不影响安全有效性
- [ ] **生物相容性评价**：接触人体产品有ISO 10993系列评价报告
- [ ] **性能测试报告**：测试标准是FDA recognized standard，样本量够
- [ ] **标签符合21 CFR 801**：UDI、符号、声明都对
- [ ] **软件文档（如适用）**：有软件描述、风险管理、V&V文档

---

## 🟡 P1级（大概率发补，但不致命）

- [ ] 510(k) Summary格式符合FDA模板
- [ ] 工程图分辨率≥300dpi
- [ ] 说明书英文翻译专业，没有中式英语
- [ ] 质量管理体系符合QMSR（2026-02-02生效）
- [ ] 灭菌验证报告完整（无菌产品）
- [ ] 货架期验证报告完整

---

## 🟢 P2级（可优化，不影响过审）

- [ ] 目录页码和书签对应正确
- [ ] 图片编号连续
- [ ] 缩写词表完整
- [ ] 参考文献格式统一

---

## 自查通过标准

| 等级 | 数量 | 要求 |
|------|------|------|
| 🔴 P0 | 必须 = 0 | 有一个没改完就不能提交 |
| 🟡 P1 | 尽量 < 3 | 超过3个建议改完再提交 |
| 🟢 P2 | 无要求 | 有时间就改 |

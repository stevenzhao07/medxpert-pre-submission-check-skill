# 欧盟MDR · CE技术文档提交前自查清单

> 提交公告机构前逐项打勾。任何P0项没打勾 = 不能提交。

---

## 🔴 P0级（必被NB打回，一个都不能漏）

### 形式审查类

- [ ] **EUDAMED Actor注册完成**：已取得SRN号
- [ ] **EU Rep信息完整**：欧盟授权代表名称、地址、协议
- [ ] **UDI分配完成**：DI-DI已分配，符合GS1/HIBC/ICCBBA标准
- [ ] **分类正确**：MDR Annex VIII规则判定正确，有书面分类理由

### 技术文档类

- [ ] **临床评价报告(CER)完整**：符合MDCG 2020-13指南
- [ ] **风险管理完整**：符合ISO 14971:2019 + GSPR全部适用条款
- [ ] **技术文档符合Annex II/III**：所有章节齐全，可追溯
- [ ] **PMS计划完整**：上市后监督计划符合MDCG 2022-15指南
- [ ] **标签语言**：目标成员国官方语言版本齐全

---

## 🟡 P1级（大概率发补，但不致命）

- [ ] 等价性论证充分（同品种比对CER）
- [ ] 生物相容性评价完整
- [ ] 灭菌验证报告完整
- [ ] 货架期验证报告完整
- [ ] 软件文档完整（SaMD/SiMD适用时）
- [ ] 公告机构选择正确：NANDO数据库里NB的认证范围覆盖你的产品

---

## 🟢 P2级（可优化）

- [ ] 文档格式统一，章节编号连续
- [ ] 参考文献格式规范
- [ ] 缩写词表完整

---

## 自查通过标准

| 等级 | 要求 |
|------|------|
| 🔴 P0 | 必须全部通过，有一个没改完就不能提交NB |
| 🟡 P1 | 尽量改完，超过5个建议改了再提交 |
| 🟢 P2 | 无强制要求 |

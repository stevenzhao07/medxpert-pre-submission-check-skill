# 中国NMPA · 注册资料提交前自查清单

> 提交器审中心前逐项打勾。任何P0项没打勾 = 不能提交。

---

## 🔴 P0级（必被发补/退审，一个都不能漏）

### 形式审查类

- [ ] **分类正确**：和分类目录/同类注册证一致，边界模糊的有分类界定意见
- [ ] **境内代理人**：境外产品已指定境内代理人，有授权书
- [ ] **产品名称规范**：符合命名指导原则，和技术要求/说明书一致

### 技术文档类

- [ ] **产品技术要求**：性能指标完整，引用标准都是现行有效版本
- [ ] **检验报告**：有资质机构出具，检验型号覆盖全规格
- [ ] **临床评价**：符合免临床目录要求（如适用），或同品种比对论证充分
- [ ] **综述资料**：结构组成、工作原理、适用范围描述准确
- [ ] **说明书标签**：符合《说明书标签管理规定》，没有夸大宣传

---

## 🟡 P1级（大概率发补，但不致命）

- [ ] 生物相容性评价完整
- [ ] 灭菌验证报告完整
- [ ] 货架期验证报告完整
- [ ] 体系核查准备充分（2026-11-01起GMP 2025版新要求）
- [ ] UDI实施时间节点确认（II类2027-06-01起）

---

## 🟢 P2级（可优化）

- [ ] 文档格式统一，章节编号连续
- [ ] 参考文献格式规范
- [ ] 中文术语统一，没有中英混用

---

## 自查通过标准

| 等级 | 要求 |
|------|------|
| 🔴 P0 | 必须全部通过，有一个没改完就不能提交 |
| 🟡 P1 | 尽量改完，发补一次通常+3-6个月 |
| 🟢 P2 | 无强制要求 |
